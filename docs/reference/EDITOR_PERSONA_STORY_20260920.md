## Offline A/B — interpretation first

**These are hand-authored synthetic comparator controls, not articles generated by the old/new Writer. No model-quality gain, actual completion rate, semantic factuality, or Ready yield is established by these scores.**

The exact old canonical prompt is frozen from the baseline Git commit, with input and prompt SHA-256 hashes. The current prompt is assembled from the same source, qualifiers, date, audience/decision conditions and formatting callbacks. Production-wrapper assembly is verified separately. Neither prompt is submitted to a provider.

Scoring uses unchanged provider-free reader/naturalness diagnostics, with equal weight for nine editorial proxy dimensions. Evidence/Fact retention is exact fixture-anchor matching, never a replacement for Production gates. Missing anchors, added numeric tokens or fabricated-experience signals make a draft ineligible for a proxy win. Unknown semantic claims still require review.

## Residual risks

- Prompt compliance and same-generation self-edit are probabilistic model behavior. Deterministic tests prove payload delivery/composition, not an unobservable internal editing pass.
- Same call count does not mean identical tokens, latency or quality-retry incidence. Existing low-thinking configuration, output limit and retry budgets remain unchanged.
- The fixture corpus is a narrow comparator control, not a representative readership/subject sample. Plain-language paraphrases can lose exact-match retention points despite preserving meaning; false semantic entailments can escape the lexical checks.
- No live Gemini or Google API validation was performed. Evidence-aligned real article comparison requires explicit permission for any new API consumption.
- Existing publication policy fingerprint includes the modified prompt files. A future merge may trigger existing policy reconciliation; this branch has not been merged and no live Notion data was updated.
