## Problem reproduced
The approved 1280×670 Decision Score card used Pillow text origins as Y positions. Noto CJK and Lato have different top bearings/ascenders, so the visible glyph group sat lower than the geometric center even when the nominal Y coordinates looked balanced.

Observed original geometry with the installed fonts:
- Outer card: y=78..592, center=335.0.
- Original visible content: title visible top y=142 to lower-card bottom y=548, center=345.0.
- Result: whole content group visually ~10px low.
- Lower metric card original text stack was visually ~9px low inside its frame.

## Fix
1. Added `_eyecatch_vertical_center_shift()`.
   - Calculates vertical correction from actual visual content bounds.
   - Current approved layout resolves to `-10px` automatically; it is not hard-coded as a manual offset.
2. Added `_draw_eyecatch_text_stack_centered()`.
   - Measures every line with Pillow `textbbox()`.
   - Centers the complete Japanese label + English subtitle + numeric score stack by visible glyph bounds.
   - Handles Noto CJK / Lato font metric differences.
3. Horizontal centering now accounts for left/right glyph bearings using `(bbox[0] + bbox[2]) / 2`.
4. Preserved:
   - 1280×670 output.
   - Decision Card geometry and visual style.
   - Lato Bold numeric font preference.
   - score-band accent colors.
   - Article Ready eligibility logic.
   - existing source-specific backgrounds.
